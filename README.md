# manufactura-configurateur

Configurateur d'escaliers Manufactura (ES-01 hélicoïdal rétractable, ES-02 droit escamotable) : couleur RAL, revêtement des marches, garde-corps.

Page autonome en un seul fichier : `index.html` (images intégrées).

Version en ligne : https://camilleoperon-hue.github.io/manufactura-configurateur/ (GitHub Pages, branche main). Les boutons « Configurer mon escalier » de manu-factura.com pointent vers cette adresse.
